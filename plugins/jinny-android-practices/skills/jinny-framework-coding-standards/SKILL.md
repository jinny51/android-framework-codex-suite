# Jinny Framework Optional Practices

This is an optional preference layer. Load and follow `android-change-policy` first;
that core Skill remains the only authority for member identity, paired patch markers,
historical authorship, evidence, and the Framework safety overlay.

Do not restate or copy mandatory policy rules here. If `android-change-policy` is not
available, stop and ask the member to update `android-framework-ops`; do not invent a
fallback policy.

When explicitly requested, apply the `legacy_jinny_style` advisory for helper-method or
utility-class naming, plus any concrete review/project preference stated by the user.
Derive any alias suffix from the selected member profile; never hardcode or copy an
example person's alias. Optional preferences cannot override mandatory policy or local
project rules.

Read `references/android-framework-coding-standards.md` for the bounded advisory.
