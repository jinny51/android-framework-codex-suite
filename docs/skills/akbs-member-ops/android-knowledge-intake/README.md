`doctor`, `daily`, `weekly`, and `patch` commands to the one implementation at
`plugins/akbs-member-ops/internal/incoming-v1/scripts/akbs_member_intake.py`.

Use the six canonical `akbs-*` Skills for new work. This compatibility directory does
not contain a kernel copy.
